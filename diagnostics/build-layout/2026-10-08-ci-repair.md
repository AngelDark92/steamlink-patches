## Local dependency access on Windows

1. Create a [classic GitHub token with read:packages](https://github.com/settings/tokens/new?scopes=read:packages&description=Steam%20Link%20local%20build).
2. Run `./tools/Configure-GitHubPackages.ps1` from the project PowerShell terminal.
   It prompts for the GitHub username and token privately, checks access to the
   pinned plugin, then saves only `gpr.user` and `gpr.key` in the user Gradle
   properties file outside source. Other properties are preserved. The stored
   token is plaintext; newly created files receive a restricted Windows ACL.
3. Run the full gate in an isolated checkout, or use `Verify-Build.ps1` for scoped
   local test/Android builds. Keep fresh-checkout skipped native audits separate
   from retained-input audit results. Never paste tokens in chat or logs.

GitHub Packages requires a classic token for local Gradle downloads; the workflow
uses its own job token. See [GitHub's Gradle registry documentation](https://docs.github.com/en/packages/working-with-a-github-packages-registry/working-with-the-gradle-registry).
